Rev4 analysis update: RK45 solver, critical unit fixes, and EDD-aligned conclusions

This commit upgrades the launcher analysis package and report artifacts to reflect
the latest physics workflow and documentation corrections requested during review.

Simulation and tooling updates:
- Add scripts/solve_launcher_rk45.py using scipy.integrate.solve_ivp(method='RK45').
- Implement Redlich-Kwong EOS with Newton-Raphson compressibility factor solver.
- Implement both choked and unchoked valve flow equations with gamma=1.30.
- Use requested ODE state set [x, v, m_c] and produce nominal + sweep outputs.
- Generate outputs/rk45_launcher_results.json, rk45_velocity_vs_orifice.csv,
  and rk45_velocity_vs_orifice.png for verification and traceability.

Report generator and content corrections:
- Update scripts/gen_doc_pandoc.py to include RK45 compliance section and EDD summary.
- Fix critical chamber-volume wording from 1.0 mL to 1.0 L (0.0010 m^3).
- Fix conclusion wording to "charged to 10 bar gauge with 1.0 L chamber volume".
- Add updated EDD summary table including recommended 8-10 mm orifice range,
  8 mm and 10 mm velocities, peak-g estimate, and launch-efficiency status.
- Keep markdown and DOCX generation in sync via the pandoc pipeline.

Regenerated artifacts:

- docs/pneumatic_launcher_analysis_complete.docx
